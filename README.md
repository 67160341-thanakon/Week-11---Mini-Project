# Week-11---Mini-Project
กลุ่มอุตสาหกรรมหนังและผลิตภัณฑ์หนัง ในรายวิชา Business Idea Creation นาย ธนากร ดวงจันทร์
เริ่มต้น
“เราต้องการมองเห็นปัญหาด้านคุณภาพในการผลิตจากข้อมูล เพื่อดูว่าปัจจัยต่าง ๆ มีแนวโน้มเกี่ยวข้องกับ Defect อย่างไร”

ต่อมา
“จาก Dashboard เราสามารถดูภาพรวมของปริมาณการผลิต ต้นทุน อัตราของเสีย และคะแนนคุณภาพได้ในหน้าเดียว”

จากนั้น
“เมื่อวิเคราะห์เพิ่มเติม เราสามารถดูความสัมพันธ์ระหว่างคุณภาพของ Supplier และ Downtime กับ Defect Rate เพื่อหาแนวโน้มที่น่าสนใจ”

แล้วเชื่อมกับบริษัท
“แนวคิดนี้นำไปสู่ LeatherVision AI ซึ่งเป็นระบบ AI และ Computer Vision ที่ทำหน้าที่เป็นตัวช่วยในการตรวจสอบคุณภาพหนัง โดยใช้กล้องถ่ายภาพและ AI วิเคราะห์ตำหนิ เพื่อช่วยให้ฝ่าย QC ตรวจพบปัญหาได้เร็วขึ้น”
